# Neo-Voxy

Far-distance rendering mod for Minecraft **1.21.1**, using LODs (levels of
detail) to render massive view distances.

Neo-Voxy started as a NeoForge port of [Voxy](https://github.com/MCRcortex/voxy)
(Fabric) and has since become an independent hard fork: it targets MC 1.21.1
only, has its own versioning, and carries features the original does not have.

## Features beyond upstream Voxy

- **Server-side LOD streaming**: a Voxy server ingests chunks and streams LOD
  sections to connected clients (client-only, server-only and auto modes;
  `/voxyadmin` resync, regen and generation commands).
- **Client-only fallback** on servers without Voxy.
- **Chunky integration**: chunks pregenerated by Chunky are ingested into Voxy.
- **SSAO** on LODs.
- **Off-thread model bakery** and optional 16px model textures.
- **Sodium 0.6.x and 0.8.x** both supported from the same jar.
- **RocksDB store auto-recovery** after corruption, plus many crash fixes
  (removed-mod blockstates, lock leaks, network flood).
- **F2 debug sidecar**: a context dump written next to each screenshot.

## Requirements

| Dependency | Version | |
|------------|---------|---|
| Minecraft | 1.21.1 | required |
| NeoForge | 21.1.77+ | required |
| Java | 21 | required |
| Sodium (NeoForge) | 0.6.x or 0.8.x | required (client) |
| Iris (NeoForge) | 1.8.x | optional, shader support |
| Lithium (NeoForge) | 0.15.x | optional |
| Chunky (NeoForge) | 1.4.x | optional |

Fabric support is in progress, see [`docs/fabric-port-plan.md`](docs/fabric-port-plan.md).

Known incompatibility: BetterFpsDist.

## Building

This is a **source-only** fork: build it yourself (see License).

```bash
scripts/setup-dev.sh        # first clone: ensures a JVM, then builds
./gradlew build             # jar in neoforge/build/libs/
```

On Windows, `scripts/setup-dev.ps1` does the same as `setup-dev.sh`, and
`scripts/deploy-local.bat` builds and copies the jar into your Minecraft
`mods/` folder and the local test server.

## Repository layout

| Path | Content |
|------|---------|
| `common/` | Loader-agnostic code (~95%), resources, unit tests |
| `neoforge/` | NeoForge entry point, event wiring, platform services |
| `buildSrc/` | Shared Gradle conventions (MultiLoader Template) |
| `docs/` | Plans, decisions (`DECISIONS.md`), progress logs, analyses |
| `scripts/` | Dev environment setup and local deploy helpers |
| `dev/` | Local runtime state (test servers), gitignored except its README |
| `.github/` | CI workflows |
